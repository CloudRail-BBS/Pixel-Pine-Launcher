## Pixel-Pine-Launcher 0.1.3 预览版

这一版新增 **Android 原生客户端**，扩展管理补上了与社区加载器的兼容检查，
官网也换了一版更安静的排版。

### 新增

- **Android 原生客户端**（Kotlin + Jetpack Compose）
  - 市场：搜索、分页、详情与版本列表，直接用系统下载器把包存到「下载」
  - 库：扫描 `Rusted Warfare/mods/units`，列出目录与 `.rwmod` 的文件数与体积
  - 设置：市场地址、游戏目录、文件访问权限与关于页
  - 与桌面端共用同一套市场接口，不引入第二份协议
- **扩展兼容层检查**
  - 同一 `id` 被多个 jar 声明、依赖在启用目录里找不到、同名文件同时存在于
    启用与停用目录——这三类问题会在扩展页直接标出来
  - 仍然只做文件管理：不加载、不注入，不算加载顺序，也不做版本求解
- **官网**
  - 首页改为黑场巨字 + 胶囊按钮的排版，新增滚动进场与轻视差
  - 新增 `/docs` 与 `/docs/pplx`，扩展规范有了在线版本
  - 下载区加入 Android

### 变更

- 扩展页的 PPL 卡片会把加载计划里的问题归到具体扩展上
  （循环依赖 / 缺依赖 / API 过高），不用再对着顶部汇总逐个猜
- 浏览器预览（`npm run dev`）下扩展页有演示数据，能直接看到坏包与缺依赖的样子

### 已知限制

- **Android 包是调试签名**，只用于预览。Play 商店未上架，安装时需要允许「未知来源」
- Android 端目前是**市场 + 库 + 设置**：不做预设切换（手机上没有必要搞多套预设），
  也不做自更新；升级方式是重新下 APK
- 读 `mods/units` 在 Android 11 以上需要「所有文件访问」，首次进入库页会引导授权
- 扩展的运行时仍未接入：启动器能装、能排序，但游戏进程还不会应用它们
