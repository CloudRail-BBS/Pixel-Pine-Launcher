01 Loadout

一套玩法，一个预设

游戏只认一个 mods/units 目录，所有 Mod 混在一起，换个玩法就得手动搬文件。PPL 把它换成一个链接：切换预设 = 重建一次链接，零拷贝、毫秒级。

  • 同一个 Mod 的多个版本可以共存，各自挂在不同的预设里
  • 冲突检测按单位目录求交集，装之前就告诉你谁会覆盖谁
  • 禁用只是改一个标记，不碰磁盘上的任何文件
作战预设 3 套
  • 现代战争 12 个 Mod · 已挂载
  • 星际远征 8 个 Mod · 2 个冲突
  • 原版 0 个 Mod

02 Market

找 Mod 不用再翻压缩包

内置资源市场，支持接入多个数据源。搜索、详情、版本历史、举报都在同一个界面里；上传要过邮箱验证与人工审核，装完立刻出现在库页的状态里。

  • 多市场源：默认官方源，也能填任意兼容的第三方地址
  • 安装前做安全校验：路径穿越、可执行文件、压缩炸弹
  • 升级会清掉旧版本文件，卸载不留残渣

03 Cross-platform

三个平台，同一套体验

安装包同时出 Windows、Linux、macOS。预设挂载在各自平台上用最合适的方式实现：Windows 用 NTFS 目录联接，不需要管理员权限；macOS 与 Linux 用符号链接。

  • macOS 认 .app 包，自动找到包内真正的可执行文件
  • Linux 认没有扩展名的原生二进制，也能识别 Steam 库
  • 自动更新用同一份签名清单，三个平台各自取自己的那一条
运行平台 已识别当前系统
  • Windows x64 · NSIS 安装包
  • Linux x64 · AppImage / deb
  • macOS arm64 / x64 · dmg

04 Extensions

扩展归你管

自己的一套扩展规范：ppl-extension.json 描述依赖与加载顺序，加载器按拓扑排序决定谁先谁后，成环的整组跳过而不是随机崩。

  • 依赖是硬边，加载顺序是软边，冲突时不会互相顶掉
  • 能只读识别社区 RWML 扩展包，默认不加载，开关在你手上
  • 停用的扩展移进 .disabled/，随时能改回来
扩展 PPL / RWML
  • 战役扩展包PPL
  • 统计面板PPL
  • 旧版兼容层RWML
  • 快捷键重绑PPL
加载顺序：战役扩展包 → 快捷键重绑 → 统计面板
